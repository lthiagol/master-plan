### Three lessons that recurred across all sessions (load-bearing)

#### Lesson 1: Lane notifications must be SHELL COMMANDS, not printed text
M200 cycle 1: runner printed notification in TUI instead of running
`herdr agent prompt`. M201 cycle 1: runner fabricated the lifecycle claim
entirely. M202 cycle 1: 11 findings with placeholders / generic strings.
The word "notify" is interpreted as "print" by opencode agents by default.
**Fix:** every lane prompt must show the exact shell command for the
notification. Codified in R4 / M237.

#### Lesson 2: Per-AC evidence discipline (FOURTH repeat — load-bearing)
M200 F-12, M201 F-05, M202 F-13, plus 11 in sessions 2-3 all had a
"summary" / "completion" commit overwriting per-AC evidence. Three
milestones, three occurrences plus the 11 runner-discipline failures.
**Fix:** evidence restoration via `mp milestone criterion pass <AC>
--evidence "..."` is the only safe path. NEVER have a
completion-summary commit touch evidence fields. Schema-level
type-check (regex) is the durable answer.

#### Lesson 3: Orchestrator must verify state independently
M200: state at `executed` but review-pass event lost. M201 cycle 1:
runner claimed "lifecycle=executed" but state was at approved/planned.
**Fix (R5):** before accepting a lane's "done" notification, run the
`mp show milestone + grep activity.json` cross-check; if any assertion
fails, REJECT and send back. Codified in M226 (production wiring) and
M237 (defaults-on activity emission).

### M225/M226 "no production caller" pattern (5 occurrences)

The runner implements primitives, exports them, tests them — but does
NOT wire them into the production hot path. Tests pass because they
call the library directly. Caught in:
- M210 F-01 (rendered_for function bypassed)
- M224 F-02 (gate worktree path check missing)
- M225 F-01/F-02 (reconcile primitives exported, never called)
- M226 F-01/F-02/F-03 (LifecycleClosure/topology_preflight no caller)
- M215 F-01 (picker/override panel never wired)

Mitigation: production-path regression tests with `m226_f0*_production_path_*`
naming convention; F-01 regression-test-with-temporary-revert baked into
the runner contract.

### F-02 pre-empt pattern (15 occurrences)

Every autopilot milestone spec from 09412e2 has placeholder AC
verifications. The orchestrator pre-empts by running
`mp milestone ac bulk <id> --bulk f02-bulk.json` BEFORE dispatching the
runner. Saves a review cycle every time. Codified as a permanent pre-
dispatch checklist item.
