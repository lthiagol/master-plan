# `mp next`

**Usage:**

```text
Usage: next [OPTIONS]
```

**Options:**

| Flag | Description |
|------|-------------|
| `--lane` | M102: lane selector — default = execution head; with --lane, returns that lane's head item. Affects which list the `head` projection reads from |
| `--summary` | Skip per-lane counts + effort rollup (default reads just the head) |
